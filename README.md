## 本人完成的工作

独立完成原创歌曲作词、故事剧本及 **10+ 镜头分镜**；使用可灵 AI 与 Prompt 保持人物一致，完成中日双语字幕、剪辑和音画合成。

歌曲作词、剧本、分镜、Prompt 与剪辑由本人完成，画面由 AI 工具生成。

## 制作流程

```text
故事与歌词
   ↓
角色定妆 → 分镜首帧 → 图生视频
   ↓
剪辑 → 中日双语字幕 → 音画合成
   ↓
2分38秒成片
```

人物一致性主要通过角色设定、首帧选择与 Prompt 调整控制。相关制作文件保留具体分镜及提示词，便于对照成片查看。
